# Data Loom hooks

Run the regression hook in a CI job before rollout. Use a wallet signed in to Data Loom and store its current 12-hour session value as the masked CI secret `DATALOOM_SESSION`. Pin the production release gate public key from `/api/release-gates` in `DATALOOM_GATE_PUBLIC_KEY`. Use a trusted CI runner. The job needs permission to read the benchmark and prepare a paid trial.

Provide a JSON file with `dataset` (dataset UUID), `benchmark` (expected dataset commitment), `models` (baseline and candidate IDs), `revision` (commit SHA), and `minimumAccuracy` (integer percentage). Add `promptFile` to evaluate candidate instructions appended to the standard benchmark system prompt. For a prompt-only change, repeat the same model ID. Invoke `node public/tools/regression-hook.mjs config.json scorecard.json`. The buyer approves the transaction from the trial history in Data Loom. The job downloads the aggregate scorecard and signed gate receipt after finalization. It exits nonzero on a failed gate, missing receipt, or unavailable trial. Set `trialId` in the config to resume waiting for an existing trial. Keep scorecards in private CI artifacts. This flow requires verified confidential inference and paid trials.

The settlement hook runs in the persistent Data Loom server. Set `SETTLEMENT_WEBHOOK_URL` to the finance team's HTTPS endpoint and `SETTLEMENT_WEBHOOK_SECRET` to a shared secret of at least 32 characters. It sends finalized dataset purchases and AI query purchases, including earlier confirmed purchases still in the database. Amounts are decimal strings in token base units. The event includes a separate USDC buyback reserve where applicable.

Verify `X-Data-Loom-Signature` as `sha256=` followed by the hex HMAC-SHA256 of the `X-Data-Loom-Timestamp` value, a literal dot, and the raw request body. Compare signatures in constant time and reject stale timestamps. Deduplicate on `Idempotency-Key`, which is the Solana transaction signature. Return a 2xx after successfully storing the event. Failed deliveries retry after the lease expires, including after a server restart.
