Contributor guide: prepare a benchmark
Store a private dataset in Account whose content is a JSON array of 5–20 cases. Each case has a prompt, expectedAnswer and optional category. Each category needs at least five cases. Use short, objectively scored answers. Never put confidential test cases in the public title, description or preview. Leave file-download and ordinary answer-access listings disabled.
[{"prompt":"What is 2 + 2? Answer with a number.","expectedAnswer":"4","category":"Arithmetic"}, ...]
Scoring: Unicode-normalized, case-insensitive exact match with collapsed whitespace. This is not a semantic or human quality judge. Scores can reveal statistical information. Uploading or opting in cannot make an already published answer key secret again.
